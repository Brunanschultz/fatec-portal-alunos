# Portal do estudante FATEC

Este projeto é uma aplicação web desenvolvida para alunos da FATEC, onde é possível realizar várias atividades, como visualizar alunos, professores, fazer avaliações e interagir com materiais acadêmicos. Ele inclui funcionalidades como um marketplace de habilidades, upload de arquivos acadêmicos e organização de pastas por disciplina.

## Funcionalidades

- **Página de Alunos**: Visualize alunos cadastrados e pesquise por nome.
- **Fórum**: Alunos podem responder dúvidas de outros alunos
- **Página de Professores**: Visualize informações dos professores e envie avaliações.
- **Marketplace**: Alunos podem oferecer serviços e produtos com preços de venda.
- **Sistema de Arquivos**: Crie pastas por disciplina e faça upload de arquivos (ex: provas, trabalhos).
- **Autenticação**: Requer login para acessar algumas funcionalidades.

## Tecnologias Utilizadas

- **Next.js** (v13) para a estrutura da aplicação, utilizando TypeScript
- **Supabase** para banco de dados, autenticação e armazenamento de arquivos
- **Tailwind CSS** para estilização
- **React** para a interface de usuário
- **PostgreSQL** no Supabase como banco de dados

## Requisitos

- **Node.js** (v16 ou superior)
- **Yarn** ou **npm** para gerenciamento de pacotes
- **Supabase**: Você precisará configurar um projeto no Supabase.

## Como Rodar o Projeto Localmente

### Passo 1: Clonar o Repositório

Primeiro, clone o repositório do projeto para o seu ambiente local.

```bash
git clone https://github.com/seu-usuario/fatec-student-portal.git
cd fatec-student-portal
```

### Passo 2: Instalar Dependências
Instale as dependências do projeto usando npm ou yarn:

Usando npm:

```bash
npm install
```

### Passo 3: Rodar o Servidor Local

Agora, você pode rodar o servidor de desenvolvimento:

Usando npm:
```bash
npm run dev
```

O projeto estará disponível no seu navegador em:

http://localhost:3000
